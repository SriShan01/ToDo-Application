# Fullstack TODO - Frontend

## Tech
- React (Vite), Tailwind CSS, Material UI, react-hook-form, Yup, axios, react-toastify

## Setup
1. Install:
   npm install

2. Edit `.env`:
   VITE_API_BASE=http://localhost:4000/api

3. Run:
   npm run dev

## Features
- List todos, create, edit, toggle done, delete
- Form validation with yup (client-side)
- Optimistic UI updates for add/edit/delete
- Friendly error messages via toast

## Assumptions / Limitations
- No authentication
- Small app expected to run locally with a single backend API
